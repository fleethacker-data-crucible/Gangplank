Connection troubleshooting

Order of use: an environment variable (GITHUB_TOKEN, GITLAB_TOKEN, GANGPLANK_AI_TOKEN), then a token saved here, then Lazarette if it is turned on.

A 401 means the provider rejected the token. A 403 usually means permissions, SSO, or scopes. A 404 can mean the URL is incorrect or the account cannot access the repository.

Privacy and AI

Gangplank Assist is advisory; it cannot execute commands or edit files. Your chat text and project name are sent only to your configured, approved model gateway. No source code is uploaded to AI automatically.
