CREDENTIAL CONNECTIONS

Arc & Integrations

Keystone uses the same Arc vault as your other PowerShell tools. Authentication happens once in the Keystone PowerShell window, before the browser server starts.

Arc vault status

Checking Arc…

If Arc is locked, restart Keystone and complete CAC + TOTP in its own PowerShell window. An already-unlocked separate Arc window does not share its in-memory session.

Provider credentials

Only service names and readiness are displayed here. Keystone never sends token values to your browser.

Connection troubleshooting

GitHub uses the Arc item github; GitLab uses gitmil; GenAI uses genapi by default. If your item has a different name, select it above and save the mapping.

A 401 means the provider rejected the token. A 403 usually means permissions, SSO, or scopes. A 404 can mean the URL is incorrect or the account cannot access the repository.

Privacy and AI

Keystone Assist is advisory; it cannot execute commands or edit files. Your chat text and project name are sent only to your configured, approved model gateway. No source code is uploaded to AI automatically.

KEYSTONE_AI_URL · KEYSTONE_AI_MODEL · GENAI_TOKEN / ARC genapi

Compatibility

Windows PowerShell 5.1, a browser, GitHub or GitLab API access. The backend stays on localhost. Ctrl+C in its PowerShell window stops it.
